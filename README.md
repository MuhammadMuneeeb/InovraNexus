# Inovra Nexus Website

Static multi-page website for Inovra Nexus with AI-first positioning and enterprise-focused conversion flow.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

From the project root:

```powershell
python -m http.server 8080
```

Then open:

- `http://127.0.0.1:8080/`
